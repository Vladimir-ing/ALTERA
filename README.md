# ALTERA — AI Products & Creative Systems

Главный лендинг ALTERA: хиро-блок, витрина проектов, раздел «Подход» и контакты.
Сайт двуязычный — русский и английский. Без фреймворков и сборки: `index.html`,
`style.css`, `lang.js`, `favicon.svg`.

Рабочий адрес: https://vladimir-ing.github.io/ALTERA/

## Где живёт проект

Проект существует в двух местах, и они должны совпадать:

| Где | Что это |
|---|---|
| `C:\Users\PC\Documents\Z.Ai\ALTERA\ALTERA_Lending` | рабочая папка на компьютере |
| https://github.com/Vladimir-ing/ALTERA | GitHub, отсюда собирается живой сайт |

**Правило: любая правка должна попасть в оба места.** Живой сайт
`vladimir-ing.github.io/ALTERA` собирается из ветки `main` на GitHub — правка,
сделанная только в папке на компьютере, на сайт не попадёт. А правка, сделанная
только на GitHub, пропадёт из папки, и в следующий раз её легко затереть.

### Забрать изменения с GitHub в папку

```bash
cd "C:\Users\PC\Documents\Z.Ai\ALTERA\ALTERA_Lending"
git pull
```

Если папка пустая или в ней нет `.git`, забери проект целиком:

```bash
cd "C:\Users\PC\Documents\Z.Ai\ALTERA"
git clone https://github.com/Vladimir-ing/ALTERA.git ALTERA_Lending
```

Имя папки на компьютере (`ALTERA_Lending`) отличается от имени репозитория
(`ALTERA`) — поэтому в команде `clone` имя папки указано в конце явно.

### Отправить изменения из папки на GitHub

```bash
git add .
git commit -m "коротко, что изменил"
git push
```

Через минуту-две после `push` в `main` живой сайт обновится сам.

### Если правки пришли в отдельной ветке

Когда работа приходит не в `main`, а в ветке, сначала влей её через
**Merge pull request** на GitHub, и только потом делай `git pull` в папке —
иначе `git pull` принесёт старую версию `main` без этих правок.

## Два языка

Сайт переключается между русским и английским кнопками `RU` / `EN` в шапке.
Отдельной английской страницы нет и словаря в отдельном файле тоже нет:
**английский текст лежит в атрибуте `data-en` рядом с русским**, в той же строке.

```html
<p data-en="English text">Русский текст</p>
<h2 data-en="Products that<br><span>already work.</span>">Продукты, которые<br><span>уже работают.</span></h2>
```

Правило простое: **правишь русский текст — правь `data-en` в том же теге.**
Так они не разъедутся. Если `data-en` не поставить, в английской версии
останется русский текст.

Внутри `data-en` можно использовать теги — `<br>`, `<span>`, `<em>`: подставляется
готовый кусок разметки, а не просто строка. Кавычки внутри значения нужно
писать как `&quot;`.

Отдельно устроены два случая:

| Что | Как переводится |
|---|---|
| `<meta name="description">` | тот же `data-en`, подменяется атрибут `content` |
| `aria-label` для читалок экрана | атрибут `data-en-aria` на том же теге |

Всё остальное делает `lang.js`. Он же запоминает выбор языка в браузере и при
первом заходе включает русский тем, у кого русский язык в браузере, и английский
всем остальным. В `index.html` текст хранится по-русски — поисковики видят
русскую версию.

Заголовок `<title>`, надписи в хиро-визуале (`THE CORE OF ALTERA`, `CREATE`,
`BUILD`), строка `KRASNOYARSK · WORLDWIDE` и подписи вроде `01 / PROJECTS`
одинаковы в обоих языках — они не переводятся намеренно.

## Витрина проектов

Карточки в секции `#projects` — это и есть витрина наработок ALTERA. Каждая
карточка выглядит так:

```html
<a class="project-card purple" href="АДРЕС" target="_blank" rel="noreferrer">
  <div class="project-meta"><span>03</span><span class="live"><i></i> LIVE</span></div>
  <div class="project-main"><p data-en="SHORT LINE">КОРОТКАЯ ПОДПИСЬ</p><h3 data-en="NAME">НАЗВАНИЕ</h3><span class="project-arrow">&#8599;</span></div>
  <p class="project-description" data-en="One or two sentences about the product.">Одно-два предложения о продукте.</p><div class="project-line"></div>
</a>
```

Цвет свечения задаётся вторым классом: `blue`, `pink`, `purple`, `cyan`, `orange`.
Номера карточек (`01`, `02`, `03`) идут по порядку.

Сетка подстраивается под число проектов: до трёх карточек в ряд на широком экране,
две на планшете, одна на телефоне. Пустых мест в ряду не остаётся — пока проектов
два, они растягиваются на всю ширину.

Добавлять карточки руками не обязательно — в корневой папке
`C:\Users\PC\Documents\Z.Ai\ALTERA` лежит скрипт `add-project.ps1`.
Он показывает, какие проекты уже выведены на лендинг, какие ещё нет, и вставляет
новую карточку с правильной разметкой, номером и английским переводом. Подробности — в файле
`ОБНОВЛЕНИЕ-САЙТОВ.md` там же.

## Проверить перед публикацией

- Открой `index.html` двойным кликом и пролистай на узком окне — вёрстка не должна ломаться.
- GitHub Pages чувствителен к регистру в путях, Windows — нет. Имена файлов только строчными.
- После `push` подожди 1–2 минуты и обнови живой сайт с `Ctrl+F5`.

## Публикация на GitHub Pages

Настроено в **Settings → Pages**: источник — ветка `main`, папка `/ (root)`.
Дальше любой `git push` в `main` обновляет сайт автоматически.
