# Дизайн-документ: перестилизация лендинга ALTERA

Дата: 19 августа 2026. Согласовано с владельцем.

## Задача

Полная смена визуального стеня лендинга ALTERA (секции и тексты остаются)
по образцу aimastodont.com: чёрно-золотая «терминальная» эстетика.
Двуязычность RU/EN сохраняется, механизм data-en и lang.js не меняются.

## Визуальный язык

Палитра:
- фон `#050507`, поднятые поверхности `#0a0a0f`, карточки `#0c0c10`, hover `#111117`
- главный акцент — золото `#daa520` (+ яркий `#ffd95a`, приглушённые золотые
  свечения `rgba(218,165,32,.12)`, рамки `rgba(218,165,32,.3)`)
- текст `#e8e8ed`, приглушённый `#8a8aa0`, мельчайшие подписи `#555570`
- рамки `rgba(255,255,255,.06–.15)`, пунктир `rgba(255,255,255,.08)`
- статус LIVE — зелёный `#22c55e`
- 5 цветовых акцентов проектов (blue/pink/purple/cyan/orange) сохраняются
  точечно: цветной номер карточки. Классы не переименовываются —
  add-project.ps1 продолжает работать.

Типографика (Google Fonts, как у фотостудии и образца):
- заголовки и логотип — Unbounded (400–800)
- служебные подписи, кнопки, меню, номера секций — Space Mono (400/700),
  капслок, мелкий кегль, широкая разрядка
- основной текст — Inter (300–600)

Эффекты: сетка-фон hero, золотая скан-линия, всплывающие частицы,
глитч-тень заголовка при наведении, орбита в золотых тонах, бегущая строка
контурным золотом, пунктирная золотая рамка у манифеста.
`prefers-reduced-motion` отключает всё.

## Секции

Структура index.html сохраняется: topbar → hero (орбита) → 01/проекты →
02/подход → манифест → 03/контакты (футер). Из HTML-правок только:
подключение шрифтов, og:image (логотип из assets/), контейнер частиц в hero,
пунктирная рамка вокруг этимологии манифеста.

## Публикация

Коммит «Перестилизовать лендинг под чёрно-золотой терминальный стиль»,
push в main, проверка живого сайта. Перед работой папки AI_CORE и
AI_TERRA-Photo-Studio вынесены из ALTERA_Lending в корень, логотипы
переложены в ALTERA_Lending/assets/ (часть Этапа 0 из ПЛАН-ДЕЙСТВИЙ.md).
